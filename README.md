## 📖 项目简介

**包河消防 App** 服务于消防监督执法人员的日常业务流程。通过移动终端实现巡查任务接收、现场隐患拍照取证、电子化整改通知书下发与整改复查闭环。

---

## ✨ 核心业务功能

- 📋 **巡查任务分配与接收**：现场扫码核验单位消防主体资格与责任人信息。
- 📷 **现场多媒体取证**：支持离线隐患填报、图片水印打卡与定位绑定。
- 📑 **电子整改台账**：隐患级别评估、限定整改期限倒计时与复查流转。
